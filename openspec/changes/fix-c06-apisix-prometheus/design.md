## Design

Keep `plugin_attr.prometheus.enable_export_server=true` and its exporter bound to loopback. Replace route 1011's `public-api` upstream with a loopback upstream to `127.0.0.1:9091`; preserve the existing 9080 gateway access policy and Docker deployment contract. Prometheus continues targeting `falcone-apisix:9080` unchanged. P3 primary operator/SRE owns operation, P4 constrained/read-only auditor verifies the contracted surface, P13 adjacent/adversarial actor receives no new listener/Service/Ingress and cannot reach 9091 outside the pod, and P18 installer gets compatible defaults. Bound upstream failures remain gateway errors. Rollback is a config revert to `public-api` (restoring the prior 404 behavior) without changing exporter runtime settings. Scope is gateway config, exporter runtime wiring, Prometheus contract, docs, and tests; UI, backend, audit, and quota changes are not applicable.
